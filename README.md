# 게시판 서비스(백엔드)
스터디를 위한 개인 프로젝트 입니다.

## 개발 환경
- Intellij IDEA Ultimate
- JAVA 17
- Spring Boot 3.4.0

## 세부 기술 스택
- Spring Web
- Spring Data JPA
- QueryDSL
- H2 Database
- Validation
- Spring Security
- OAuth2 Client
- Lombok
